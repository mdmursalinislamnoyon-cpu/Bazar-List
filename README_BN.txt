আমার বাজার তালিকা — Android অ্যাপ প্রজেক্ট

এই ZIP-এ Android Studio-তে খোলার মতো সম্পূর্ণ প্রজেক্ট আছে।
অ্যাপটি WebView দিয়ে আপনার দেওয়া HTML-কে অফলাইনে চালায়।
পণ্যের তালিকা ও হিসাব Android WebView-এর স্থানীয় storage-এ থাকে।
প্রিন্ট/PDF বোতাম Android-এর Print service খোলে।

APK বানানোর নিয়ম:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio থেকে Open নির্বাচন করে AmarBazar ফোল্ডারটি খুলুন।
3. Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
5. APK পাওয়া যাবে: app/build/outputs/apk/debug/app-debug.apk

নোট: এই পরিবেশে Android SDK/Gradle build tool নেই, তাই এখানে সরাসরি APK compile করা সম্ভব হয়নি।
